NECESITAS AYUDA

Bienvenido al centro de ayuda de TIERRA ROSA. En esta sección encontrarás información para orientarte sobre el funcionamiento de la aplicación, tu cuenta, la tienda y las diferentes opciones disponibles.

Si tienes algún problema, revisa primero la información de esta página antes de volver a intentarlo.

¿Cómo puedo iniciar sesión?

Para iniciar sesión puedes utilizar las opciones disponibles en la página principal de Tierra Rosa.

Dependiendo de la configuración de la aplicación podrás utilizar usuario y contraseña o los enlaces de acceso disponibles.

Recuerda no compartir tus contraseñas con otras personas.

¿Cómo puedo crear una cuenta?

Si todavía no tienes una cuenta, selecciona la opción Registrarme Aquí.

Completa los datos solicitados y guarda la información. Revisa que tu correo electrónico, teléfono y demás datos estén escritos correctamente.

¿Olvidaste tus datos de acceso?

Si no recuerdas tus datos de acceso, utiliza las opciones de recuperación disponibles en la aplicación.

Por seguridad, Tierra Rosa no debe solicitarte que publiques una contraseña en redes sociales, comentarios o mensajes públicos.

¿Cómo funciona la tienda?

En la tienda puedes buscar productos de maquillaje, cosméticos, cuidado de la piel, cabello, uñas y otras categorías relacionadas con belleza.

  • Utiliza el buscador para encontrar productos.
  • Consulta las categorías disponibles.
  • Revisa el precio mostrado.
  • Observa las promociones y descuentos.
  • Agrega productos al carrito.

¿Cómo funciona mi perfil?

El perfil permite guardar información personal que tú decidas proporcionar a la aplicación.

Puedes agregar fotografía, descripción, enlaces web, redes sociales, país, correo electrónico, teléfono, ocupación y zona horaria.

Antes de compartir información personal, asegúrate de comprender para qué será utilizada.

¿Qué hago si una imagen no aparece?

Algunas imágenes de una página web pueden depender de una conexión a Internet o de un servidor externo.

Si una imagen no aparece correctamente:

  • Comprueba tu conexión a Internet.
  • Actualiza la página.
  • Comprueba que el enlace de la imagen sea correcto.
  • Intenta abrir nuevamente la página.

¿Qué hago si un botón no funciona?

Comprueba primero que el archivo correspondiente se encuentre en la misma carpeta que la página.

Por ejemplo, si un botón apunta a:

index.html

ese archivo debe existir exactamente con ese nombre.

En Acode también debes comprobar que no hayas cambiado accidentalmente el nombre del archivo.

¿Qué hago si un enlace de una red social no funciona?

Los enlaces de redes sociales pertenecen a servicios externos. Si una cuenta cambia su nombre de usuario, privacidad o dirección, el enlace puede dejar de funcionar.

En ese caso, comprueba el enlace directamente en la plataforma correspondiente y actualízalo en Tierra Rosa.

Seguridad

  • No compartas contraseñas.
  • No publiques códigos de recuperación.
  • No entregues códigos de verificación a desconocidos.
  • Comprueba que estás utilizando sitios oficiales.
  • No proporciones información personal innecesaria.
  • Utiliza contraseñas diferentes para servicios importantes.

Privacidad

Tierra Rosa debe utilizar la información de los usuarios de manera responsable y explicar claramente qué información se recopila, para qué se utiliza y cómo puede administrarse.

Antes de autorizar el uso de información personal, revisa las condiciones y políticas correspondientes.

¿Necesitas más ayuda?

Si una función no funciona correctamente, revisa nuevamente los datos introducidos y la conexión a Internet.

También puedes regresar a la página principal para acceder nuevamente a las diferentes opciones de Tierra Rosa.
